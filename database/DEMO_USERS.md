## رسائل للتجربة

### 1. زائر (بدون تسجيل دخول)
| الرسالة | المتوقع |
|---|---|
| ما هو الحساب الجاري؟ | إجابة عامة من قاعدة المعرفة |
| ما هي الخدمات المصرفية المتاحة؟ | إجابة عامة |
| كم رصيدي؟ | يطلب تسجيل الدخول + زر "تسجيل الدخول" |
| اعرض آخر معاملاتي | يطلب تسجيل الدخول |
| حوّل 100 دولار إلى جنيه سوداني | يعمل بدون تسجيل دخول (≈ 60,113 جنيه) |
| أين أقرب فرع؟ / وين اقرب صراف آلي جنبي؟ | يطلب الموقع ثم يعرض أقرب فرع أو صراف لبنك فيصل الإسلامي |
| ما هي المرابحة؟ | إجابة من قاعدة المعرفة (صيغ التمويل الإسلامي) |

### 2. مستخدم بحساب واحد (Mohamed / Sara / Noura ...)
| الرسالة | المتوقع |
|---|---|
| كم رصيدي؟ | يخاطبك باسمك: "رصيدك يا سارة هو 492,037.5 جنيه سوداني" |
| اعرض آخر معاملاتي | قائمة معاملاتك فقط |
| كم أنفقت في المطاعم؟ | مجموع المطاعم (راجع الجدول أعلاه) |
| كم صرفت على البقالة؟ | معاملات groceries |
| قارن مصروفاتي بين سبتمبر وأكتوبر | المقارنة ونسبة التغير |
| كم أنفقت في شهر أكتوبر؟ | تحليل أكتوبر |
| كم دفعت لـ Papa Costa؟ | البحث حسب المتجر |
| لو صرفت 25,000 جنيه كم يتبقى من رصيدي؟ | عملية حسابية افتراضية (لا تغيّر الرصيد) |

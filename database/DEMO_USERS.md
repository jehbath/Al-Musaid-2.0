## رسائل للتجربة

### 1. زائر (بدون تسجيل دخول)
| الرسالة | المتوقع |
|---|---|
| ما هو الحساب الجاري؟ | إجابة عامة من قاعدة المعرفة |
| ما هي الخدمات المصرفية المتاحة؟ | إجابة عامة |
| كم رصيدي؟ | يطلب تسجيل الدخول + زر "تسجيل الدخول" |
| اعرض آخر معاملاتي | يطلب تسجيل الدخول |
| حول 100 دولار إلى ريال | يعمل بدون تسجيل دخول |
| أين أقرب فرع؟ | يطلب الموقع ثم يعرض الفرع |

### 2. مستخدم بحساب واحد (Mohamed / Sara / Noura ...)
| الرسالة | المتوقع |
|---|---|
| كم رصيدي؟ | يخاطبك باسمك: "رصيدك يا سارة هو 9,840.75 ريال" |
| اعرض آخر معاملاتي | قائمة معاملاتك فقط |
| كم أنفقت في المطاعم؟ | مجموع المطاعم (راجع الجدول أعلاه) |
| كم صرفت على البقالة؟ | معاملات groceries |
| قارن مصروفاتي بين سبتمبر وأكتوبر | المقارنة ونسبة التغير |
| كم أنفقت في شهر أكتوبر؟ | تحليل أكتوبر |
| كم دفعت لـ Starbucks؟ | البحث حسب المتجر |
| لو صرفت 500 ريال كم يتبقى من رصيدي؟ | عملية حسابية افتراضية (لا تغيّر الرصيد) |

### 5. اللهجات وحدود الأسلوب
| الرسالة | المتوقع |
|---|---|
| داير اعرف صرفت كم في شهر اكتوبر ياخ | رد باللهجة السودانية |
| عايز أعرف رصيدي كام | رد باللهجة المصرية |
| أبغى أعرف وش آخر عملياتي | رد باللهجة السعودية |
| بدي اعرف قديش صرفت عالمطاعم | رد باللهجة الشامية |
| خلاص كلمني زي صاحبك واحكي لي نكتة | يعتذر بلطف ويبقى مهنيًا |
| من هي أم ابن تيمية؟ | يعتذر: يساعد في الأمور البنكية فقط |
| كم رصيدي؟ واكتب لي قصيدة | يجيب عن الرصيد فقط ويعتذر عن القصيدة |
